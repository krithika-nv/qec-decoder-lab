# Evidence and provenance

**Evidence policy:** the repository contains small independently checked summaries and figures. Full detector-syndrome arrays, outcomes, decoder predictions, sample seeds, circuit sources, DEMs, machine-specific timing trials and audit manifests are kept in **separate immutable ZIP archives**, not in Git. Preserve these archives outside the source tree with their checksums and frozen protocols.

## Scope of independent verification

For the hybrid study, the independent review checked the archive's 115 internal file hashes, the 32 frozen source hashes, protocol checksum, raw-array shapes and logical failures, gate reconstruction, paired McNemar p-values, Holm adjustments and 36 timing records. **It did not execute a new Stim/PyMatching simulation replay, inspect physical hardware, or establish general decoder optimality.**

A simple SHA-256 check for archived files:

```bash
shasum -a 256 qec-hybrid-heldout-evidence.zip
# Compare the result to the exact digest above.
```

## Reproduction and reporting rules

1. Do not copy a historical frozen `outputs/` study into a modified source tree and call it a new experiment.
2. Keep each raw archive, exact source revision, environment versions and protocol lock together. If the algorithm changes, generate a new protocol and independent shots.
3. Preserve null results, BP convergence failures and cases favouring the baseline.
4. Report case-level statistics and adjusted p-values, not just pooled counts or cherry-picked charts.
5. Make a separate explicit statement when hardware, external replay or full published-figure reproduction has **not** been verified.

See [Validation](VALIDATION.md), [Methods](METHODS.md) and [Results](RESULTS_AND_LIMITATIONS.md).
